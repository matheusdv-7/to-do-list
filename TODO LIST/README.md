# Lista de tarefas

Aplicação Flask para criar, concluir e excluir tarefas organizadas por data.

## Executar

Na pasta `TODO LIST`, crie um ambiente virtual, instale as dependências e inicie a aplicação:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Abra <http://127.0.0.1:5000> no navegador.
